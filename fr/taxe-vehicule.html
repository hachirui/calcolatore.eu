TAXE SUR LES VÉHICULES

Calculez le malus écologique et la taxe annuelle sur les véhicules de société (TVS) pour 2026. Barèmes officiels mis à jour.

En France il n'existe pas de taxe annuelle sur les véhicules particuliers pour les particuliers (contrairement à d'autres pays). Cependant, il existe le malus écologique à l'achat (basé sur les émissions CO₂), et la TVS (Taxe sur les Véhicules de Société) pour les entreprises. Ce calculateur couvre les deux cas.

Questions Fréquentes
Qu'est-ce que le malus écologique?+
Le malus écologique (ou taxe CO₂) est une taxe payée une seule fois à l'achat d'un véhicule neuf dont les émissions dépassent un certain seuil. Pour 2025, le seuil de déclenchement est de 118 g/km. Les montants vont de 50€ à plus de 60.000€ pour les véhicules les plus polluants (au-delà de 225 g/km). Il est intégré dans le certificat d'immatriculation (carte grise).
Les véhicules électriques paient-ils le malus?+
Non. Les véhicules 100% électriques sont totalement exemptés du malus écologique. Les hybrides rechargeables bénéficient d'un barème favorable depuis 2022, basé sur leurs émissions WLTP. Certains véhicules hybrides non rechargeables peuvent également bénéficier d'exonérations partielles selon leur niveau d'émissions.
Qu'est-ce que la TVS?+
La Taxe sur les Véhicules de Société (TVS) est une taxe annuelle due par les entreprises pour les véhicules qu'elles possèdent ou utilisent. Depuis 2022, elle est remplacée par deux taxes distinctes: la taxe annuelle sur les émissions de CO₂ et la taxe annuelle sur l'ancienneté des véhicules. Les véhicules électriques sont exonérés de la taxe CO₂ mais peuvent être soumis à la taxe sur l'ancienneté.
Comment réduire le malus?+
Pour éviter ou réduire le malus: choisissez un véhicule électrique ou hybride rechargeable à faibles émissions; optez pour un véhicule d'occasion (le malus ne s'applique qu'aux véhicules neufs); vérifiez si vous êtes éligible aux aides à l'achat (bonus écologique jusqu'à 7.000€ pour les ménages modestes). Le leapfrog entre bonus et malus peut représenter plusieurs milliers d'euros selon le véhicule choisi.
